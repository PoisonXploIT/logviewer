    Guia de uso
    
      
    
    
    
    
      
    Cargar un log
    
      
    Usa el boton "Cargar archivo" de la barra lateral para subir uno o
        varios archivos (acepta .gz, .bz2, .xz y .zip). Cada archivo es una
        sesion; la activa se cambia en la lista "Sesiones".
    
      
    Filtrar
    
      
    La barra de filtros sobre la tabla combina IP, ruta, texto libre,
        nivel, codigo y rango de fechas. Con coma pones varios valores
        (OR) y con prefijo "!" excluyes (p. ej. !10.0.0.5). La tecla "/"
        lleva el foco al texto libre.
    
      
    Ver contexto de una linea
    
      
    Clic en cualquier fila abre el drawer de detalle; el boton "Ver
        contexto" muestra las lineas anteriores y posteriores del archivo
        original con la actual resaltada.
    
      
    Tail en vivo
    
      
    El boton "Tail en vivo" (o la tecla t) sigue las lineas nuevas:
        el indicador LIVE parpadea mientras entran datos y la tabla se
        actualiza sola. Vuelve a pulsarlo para apagarlo.
    
      
    Exportar
    
      
    El boton "Exportar" (o la tecla e) descarga las filas filtradas en
        CSV o JSON Lines, sin pasar por el navegador entero: el servidor
        lo envia en streaming.
    
      
    Analizar con LLM local
    
      
    Si hay un LLM local configurado, al abrir una fila aparece la
        seccion "Analizar con LLM local" en el drawer. El boton "Analizar"
        envia SOLO esa linea al modelo local (nada sale de la maquina) y
        muestra la respuesta tal cual; si repites la misma pregunta sale
        de cache, marcada con [cache]. El idioma en que responde se elige
        en los ajustes del LLM (engranaje de la cabecera): "Auto" responde
        en el idioma de la linea, o bien Espanol / Ingles fijo.
    
      
    Diagnostico rapido
    
      
    El boton "Diagnostico rapido" (icono de alerta en la barra
        lateral) manda las plantillas unicas de error del dataset activo
        (no las miles de lineas sueltas) al LLM local y devuelve una
        conclusion con las plantillas mas frecuentes y su linea de ejemplo.
        Sirve para ver el bosque en vez de 204 errores sueltos: el LLM te
        da pistas de que esta pasando en el sistema y por donde empezar.
        La primera vez tarda (el modelo razona); las siguientes salen de
        cache al instante. Requiere LLM configurado.
    
      
    Importar de Splunk
    
      
    Si Splunk esta configurado, la seccion "Importar de Splunk" deja
        pegar una query SPL y cargar su resultado como un dataset mas del
        visor (filtrar, exportar y diagnosticar igual que un archivo). El
        SPL es quien filtra y agrega; el visor solo trae lo que pidas
        (tope de filas para no saturar). Para eventos JSON de Azure AD
        (sourcetype ms:aad:signin) recuerda usar | spath para
        extraer los campos (userPrincipalName, ipAddress, failureReason)
        que van dentro del campo _raw.
